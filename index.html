FPGA board simulator

Quarsim

Write VHDL or Verilog and see exactly what the RZ-EasyFPGA A2.2 board (Cyclone IV EP4CE6E22C8) would do: LEDs, 7-segment display, buzzer and keys. No board and no Quartus needed.

Download for Windows

Windows 10/11 (64-bit) · free

Portable .zip·SHA-256 checksums·All releases

Independent student project. Not affiliated with Intel or Altera.

Features

Real toolchain

Your HDL is compiled with GHDL and Yosys, the same open-source tools engineers use, not an animation.

Board-accurate

Pins, active-low LEDs and keys, the multiplexed 7-segment display and the buzzer behave like the real A2.2 board.

Updates itself

Quarsim tells you when a new version is out and installs it in one click.

Install

  1. Download Quarsim-Setup.exe and open it.

  2. Windows may show "Windows protected your PC" because the installer is not code-signed yet. Click More info, then Run anyway.

  3. Follow the setup, then open Quarsim from the Start menu.

Requirements: Windows 10 or 11, 64-bit. About 110 MB of disk space. Microsoft Edge WebView2 (already included in Windows 11).
